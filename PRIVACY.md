# Premise Privacy Policy

Last updated: 5 November 2026

Premise is an Atlassian Forge app built for Codegeist 2026.

## What data Premise uses
Premise reads Confluence pages and Jira issues that the installing user can already access, to find decisions and check their assumptions.

## Where data is stored
All data Premise saves (decisions, assumptions, tripwire settings) is kept in Atlassian Forge storage inside your Atlassian site. Premise does not send your data to any server run by the developer.

## AI processing
Premise uses Atlassian's Forge LLM service, which runs on Atlassian infrastructure.

## Removing data
Uninstalling Premise deletes its stored data from your site.
